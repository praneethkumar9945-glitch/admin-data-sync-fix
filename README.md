# Lead Status Export

Admin Excel download with color-coded agent status

Add an Excel download button to the admin Leads page that exports all lead data (including assigned agent info and latest call outcome) with rows color-coded by outcome status. Also add missing outcome types (Visited/Visiting, Week, Parents, LC) to the call log system so agents can use them and the export reflects them.
